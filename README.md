# Tableau Workbook

This folder is intended for the Tableau workbook used in the project.

Recommended file:

- `Student_Mental_Health_Dashboard.twbx`

The workbook should connect to the prepared SQL Server table and contain the worksheets/dashboard shown in the project README.

If the `.twbx` file is too large for GitHub, upload it using Git LFS or provide a Tableau Public link in the main README.
